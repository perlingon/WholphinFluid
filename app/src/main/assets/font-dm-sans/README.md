# DM Sans font

Sourced from https://fonts.google.com/specimen/DM+Sans

Used for the interface and for text subtitles. The font files are in `res/font` (`dm_sans_*.ttf`): Light, Regular, Medium, SemiBold, Bold and ExtraBold, with italics for Light to Bold (300 to 700), which are the subtitle weights.

Licensed under SIL OPEN FONT LICENSE Version 1.1, see [OFL.txt](./OFL.txt).

Subtitles on Android 8 and later use the variable fonts in this folder (`dm_sans_variable.ttf`, `dm_sans_variable_italic.ttf`, from https://github.com/google/fonts/tree/main/ofl/dmsans), so any weight from 300 to 700 can be shown.
