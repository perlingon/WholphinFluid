# DM Sans font

Sourced from https://fonts.google.com/specimen/DM+Sans

Used for the interface and for text subtitles. The font files are in `res/font` (`dm_sans_*.ttf`): Regular, Medium, SemiBold, Bold and ExtraBold, with italics for Regular, Medium and Bold.
